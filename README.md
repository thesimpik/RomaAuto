# РоманАвто — сайт с исходными файлами

Это статический многостраничный сайт для автоплощадки «РоманАвто» в Котласе.
Используются HTML, CSS и JavaScript без сборки, базы данных и платных библиотек.

## Файлы

- `index.html` — главная страница
- `catalog.html` — каталог автомобилей
- `car.html` — страница конкретного автомобиля, данные берутся по `?id=...`
- `reviews.html` — фотоальбом покупателей
- `assets/reviews.js` — список отзывов с фото и короткими подписями
- `tools/add-car.html` — локальный помощник для подготовки карточки автомобиля и фото
- `selection.html` — подбор автомобиля под ключ
- `buyout.html` — выкуп автомобилей
- `contacts.html` — контакты
- `assets/style.css` — оформление и мобильная адаптация
- `assets/script.js` — мобильное меню, каталог и карточка автомобиля
- `assets/cars.js` — список автомобилей в продаже

## Как открыть на компьютере

1. Распакуйте ZIP-архив.
2. Откройте `index.html` двойным щелчком в браузере.
3. Проверьте страницы и ссылки.

Для работы каталога достаточно открыть сайт в современном браузере. Для публикации загрузите все файлы и папку `assets` на статический хостинг, сохранив структуру папок.

## Как проще добавлять автомобили

Откройте файл `tools/add-car.html` на компьютере в браузере. Заполните форму, выберите фотографии и нажмите «Подготовить карточку». Инструмент подготовит запись для каталога и кнопки для скачивания фото в двух размерах. Далее:
1. Скопируйте созданную запись в массив `window.ROMANAVTO_CARS` в `assets/cars.js`.
2. Создайте папку `assets/cars/<id>/` (ID указан в созданной записи).
3. Скачайте фотографии `1.jpg`, `1-sm.jpg`, `2.jpg`, `2-sm.jpg` и т.д. и положите их в эту папку.
4. Загрузите `assets/cars.js` и новую папку с фото на хостинг, сохранив структуру папок.

Помощник не требует установки программ и работает локально. Он не публикует изменения автоматически. Не размещайте `tools/add-car.html` как публичную админ-панель: она не защищена паролем. Для полностью автоматического добавления машин непосредственно на сайте потребуется серверная часть/CMS.

## Как добавлять отзывы

Для удобного добавления откройте `tools/add-review.html` в браузере. Помощник создаёт готовую запись и подготавливает фото JPG для папки `assets/reviews/`; затем нужно вставить запись в `assets/reviews.js` и загрузить оба файла на хостинг. Сам по себе помощник не публикует изменения автоматически и не является защищённой админ-панелью.


Добавьте фото в папку `assets/reviews/`, затем внесите запись в массив `window.ROMANAVTO_REVIEWS` в файле `assets/reviews.js`:
```js
{
  id: "elena-hyundai-solaris-2026",
  date: "21.08.2026",
  customer: "Елена",
  car: "Hyundai Solaris 2013 г.в.",
  photo: "assets/reviews/elena-hyundai-solaris-2026.jpg",
  caption: "Спасибо за доверие!"
}
```
На главной странице показываются первые три фотографии, а на странице `reviews.html` — весь фотоальбом. Карточки автомобилей на главной прокручиваются горизонтально; одновременно видно до трёх карточек на широком экране. Публикуйте фото и имя покупателя только с его согласия. Если вы отправите мне описание и фотографии машин/отзывов, я смогу внести их в файлы сайта и вернуть вам обновлённый архив.

## Бесплатная публикация

### Вариант 1: GitHub Pages
1. Создайте аккаунт на GitHub.
2. Создайте новый публичный репозиторий, например `romanavto-site`.
3. Загрузите все HTML-файлы и папку `assets` в корень репозитория.
4. Откройте `Settings` → `Pages`.
5. В `Build and deployment` выберите `Deploy from a branch`, затем ветку `main` и папку `/ (root)`, нажмите `Save`.
6. Дождитесь публикации. GitHub покажет адрес сайта в разделе Pages.

GitHub Pages предназначен для статических сайтов. Условия и доступность сервиса могут меняться; проверьте актуальную документацию GitHub. Бесплатный адрес обычно будет на домене `github.io`. Собственный домен необязателен.

### Вариант 2: Netlify
1. Создайте аккаунт Netlify.
2. Используйте функцию ручного развёртывания/загрузки статического сайта, если она доступна в вашем интерфейсе.
3. Загрузите папку сайта или подключите репозиторий GitHub.
4. Проверьте полученный адрес и работу всех страниц.

Тарифы и доступность сервисов следует проверить перед использованием. Не размещайте персональные данные клиентов в репозитории.

## Перед публикацией — обязательная проверка

- Снимайте с продажи проданные автомобили — удаляйте их записи из `assets/cars.js`.
- Адрес площадки: Котлас, улица 7-го съезда Советов, 62 (въезд со стороны ул. Ленина). На странице контактов встроена Яндекс Карта.
- Добавьте ссылку на профиль MAX, когда он появится.
- Добавьте полное наименование ИП и необходимые сведения о продавце.
- Проверьте все фактические заявления о качестве, опыте, режиме работы и кредитовании.
- Если добавите формы заявок или аналитику, проверьте требования законодательства РФ о персональных данных, уведомлениях, согласиях и локализации. В текущей версии формы, собирающей данные, нет.

## Что не включено

Сайт не имеет серверной части, CRM, онлайн-оплаты, административной панели или автоматической отправки заявок. Для обновления каталога нужно редактировать `assets/cars.js`. Это позволяет бесплатно разместить статический сайт, но каталог не обновляется автоматически.
